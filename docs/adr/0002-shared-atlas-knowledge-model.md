# ADR-0002：使用统一知识模型生成 Atlas 视图

- 状态：已接受
- 日期：2026-07-14

## 背景

DomainAtlas 后续需要同时提供领域总览、模块、知识节点、关系、来源证据、学习路径和自测反馈。如果每个视图独立生成内容，同一概念容易出现重复、冲突和无法追溯的问题。

## 决策

Atlas 的所有用户视图都从同一份结构化知识模型派生。模型中的节点、关系、证据和版本使用稳定标识；视图只负责选择和呈现，不保存独立的事实副本。

发布后的 `AtlasVersion` 不可变。修订内容生成新的草稿并经过校验后发布为新版本。

## 影响

- 不同视图可以引用相同的知识对象和来源；
- 学习进度与自测结果可以稳定映射到具体节点；
- 需要为节点、关系、证据和版本维护稳定 schema；
- 视图层不能绕过知识模型直接写入已发布内容。

## 当前实现备注

第一版 Demo 使用 `AtlasDocument` 作为统一知识模型，地图、详情、来源、路径和自测都引用其中的稳定 ID。不可变 `AtlasVersion` 尚未实现；当前 Atlas 随 `DemoRun` 保存在 JSON Store 中。

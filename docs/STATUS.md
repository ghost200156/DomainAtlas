# DomainAtlas 当前进度

> 最近更新：2026-07-14  
> 本文档记录“现在正在发生什么”。路线图发生变化时更新 `ROADMAP.md`，长期技术决策发生变化时新增 ADR。

## 当前阶段

**M0 已完成，准备进入 M1：学习任务与框架确认。**

当前仓库仍是技术原型。现有聊天界面用于验证领域学习对话和 Agent 流式链路，还没有实现 DomainAtlas 的核心学习产物。

## 已完成

- FastAPI 后端和 React Router 前端；
- `/agent` 流式聊天接口；
- AI SDK 到 Pydantic-AI 的消息转换；
- SSE 文本流和 Agent 消息转换；
- 基础消息校验；
- 后端单元测试；
- Ruff 和前端 TypeScript 检查；
- `LearningBrief` 和 `FrameworkPlan` 的基础 schema。

## 当前重点

1. 定义 `LearningBrief` 和 `FrameworkPlan` schema；
2. 将聊天请求转换为显式学习任务；
3. 建立任务阶段状态机；
4. 实现计划确认和修改；
5. 为结构化产物增加持久化边界。

## 尚未实现

- 研究和来源证据；
- Atlas 草稿、校验和发布；
- 节点、关系、时间线和学习路径；
- 自测、薄弱点和局部扩展；
- PostgreSQL 任务状态与版本；
- 可恢复后台任务；
- 真实生成进度和预算控制；
- 生产部署、认证、限流和监控。

## 当前风险与待确认事项

- `LearningBrief` 与 `FrameworkPlan` 的字段边界尚未固定；
- 工作流状态与 Agent 消息历史的职责需要严格分离；
- 来源证据的数据模型会影响后续 Atlas schema；
- 模型兼容服务对流式工具调用的支持程度不一致；
- 当前环境变量名称需要与实际客户端配置保持一致。

## 下一个检查点

```text
输入学习主题、背景、目标和时间预算
→ 系统校准范围

```

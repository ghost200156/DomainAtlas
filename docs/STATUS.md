# DomainAtlas 当前进度

> 最近更新：2026-07-21
>
> 本文档只描述仓库当前状态。阶段顺序见 `ROADMAP.md`，长期技术决策见 `docs/adr/`。

## 当前阶段

**第一版可运行 Demo（v0.1）已经形成，当前进入演示稳定与交付整理阶段。**

这不是完整生产产品，但核心学习闭环已经可以端到端运行：

```text
创建学习任务
→ 生成并确认 FrameworkPlan
→ 整理 ResearchPack
→ 构建和校验 AtlasDocument
→ 在迷雾地图中探索概念关系
→ 记录节点进度并完成自测
```

## 已完成

### Agent 与工作流

- Planning、Research、Atlas 三个有边界的 Agent 阶段；
- 用户确认或修改计划后才进入研究和建图；
- `PREPARING_PLAN`、`WAITING_CONFIRMATION`、`GENERATING`、`READY`、`FAILED` 状态流；
- `live`、`hybrid`、`fixture` 执行模式和失败回退提示；
- 计划、研究包和 Atlas 的结构化校验及悬空引用修复；
- 当前默认 OpenAI 兼容模型为 `qwen3.5-plus`。

### 后端

- FastAPI 任务、计划确认、重试、Atlas、事件、进度和自测 API；
- 中文维基百科受控候选资料检索，失败时使用演示资料；
- JSON Demo Store，任务保存在 `backend/data/runs/`；
- 进程内异步任务注册表；
- 保留 `/agent` 流式聊天原型；
- 后端单元测试和 Ruff 检查。

### 前端

- 首页、任务创建、计划确认、生成进度和 Atlas 探索页面；
- 全屏 SVG 矢量知识地图；
- 关系驱动的渐进解锁和动态迷雾；
- 可动画的 SVG 守护灵节点；
- 可缩放、可平移、可搜索的地图交互；
- 概念详情、来源证据、学习状态和简单自测；
- TypeScript 类型检查和生产构建。

### 文档

- 跨平台安装、配置、开发启动和生产启动说明；
- 产品定义、架构、路线图、ADR 和变更记录；
- API Key 不进入 Git 的配置边界。

## 第一版已知限制

- JSON 文件只适合单机 Demo，不支持多用户并发和事务；
- 后台任务依赖当前后端进程，重启后不会自动恢复正在生成的任务；
- 外部研究源目前仅使用中文维基百科的单条候选摘要，证据覆盖有限；
- `QualityReport` 仍以确定性检查和演示评分为主，没有独立 Reviewer Agent；
- Atlas 以 `AtlasDocument` 保存在任务中，尚无不可变版本、迁移和回滚机制；
- 没有认证、限流、调用预算、监控和正式部署配置；
- 自测仅形成最小反馈，不会自动生成个性化复习路线；
- 模型兼容服务可能在复杂结构化输出上超时，`auto` 模式会回退到演示数据。

## 当前重点

1. 保证新电脑可以按 README 一次启动成功；
2. 稳定真实模型的规划、研究和 Atlas 结构化输出；
3. 修复第一版演示中影响完成主流程的错误；
4. 保持地图可读性、节点交互和进度状态一致；
5. 准备比赛演示脚本和可重复的样例任务。

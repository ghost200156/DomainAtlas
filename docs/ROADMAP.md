# DomainAtlas Roadmap

本路线图描述产品能力的实现顺序，不替代具体 Issue。每个里程碑只保留目标、当前结果和下一阶段缺口。

状态说明：

- **Done**：目标已经完成；
- **Demo Done**：第一版演示闭环已经完成，仍存在生产化缺口；
- **Partial**：已有最小实现，尚未完成目标闭环；
- **Next**：当前优先级；
- **Later**：暂不进入近期开发。

## M0：Agent 技术链路 — Done

目标：验证前后端模型调用、流式消息和工具调用链路。

已完成：

- FastAPI 与 React Router 基础工程；
- `POST /agent` 流式接口；
- AI SDK 与 Pydantic-AI 消息转换；
- SSE 文本流、基础校验和测试；
- OpenAI 兼容模型配置。

## M1：学习任务与框架确认 — Demo Done

目标：把宽泛主题转成有边界、可确认的学习计划。

已完成：

- `LearningBrief`、范围校准和 `FrameworkPlan`；
- 创建任务和保存结构化产物；
- 计划查看、修改和确认；
- 未确认计划前不进入研究阶段；
- 任务状态和事件可重新读取。

生产化缺口：认证、多用户所有权、数据库事务和状态迁移。

## M2：研究、构建与校验 — Demo Done

目标：生成第一版带来源、可校验的 Atlas。

已完成：

- 受控中文维基百科候选资料和 `ResearchPack`；
- 模型异常时的演示资料回退；
- 包含模块、概念、关系、机制、案例、来源、学习路径和自测的 `AtlasDocument`；
- schema、引用、覆盖度和图连通性校验；
- 悬空引用修复和 `QualityReport`；
- `live`、`hybrid`、`fixture` 执行结果标识。

生产化缺口：多来源检索、来源评级、独立审阅、不可变 `AtlasVersion`、重试预算和调用监控。

## M3：Atlas 工作区与学习路径 — Demo Done

目标：让用户通过地图逐步建立领域认知框架。

已完成：

- 全屏 SVG 矢量地图；
- 模块区域、概念节点和关系路径；
- 基于已理解节点邻接关系的渐进解锁；
- 动态迷雾和 SVG 守护灵；
- 地图缩放、平移、搜索和模块定位；
- 大尺寸概念详情、证据来源和学习状态；
- 学习进度持久化到具体节点。

生产化缺口：大型图布局、地图性能基准、键盘完整导航和多种知识视图。

## M4：自测、薄弱点与局部扩展 — Partial

目标：形成最小学习反馈闭环。

已完成：

- 结构化选择题；
- `AssessmentFeedback`；
- 得分、反馈和相关复习概念 ID。

尚未完成：

- 根据薄弱节点生成复习路线；
- 有预算和父节点约束的局部扩展；
- 历史结果对比和掌握度模型。

## M5：第一版稳定与演示交付 — Next

目标：让比赛演示在新环境中可重复、可解释、可恢复到安全状态。

范围：

- 新电脑安装与启动验收；
- 固定样例和真实模型各走一遍端到端流程；
- 模型超时、网络失败和后端重启的用户提示；
- 主流程浏览器回归检查；
- 演示脚本、截图和版本变更记录；
- 清理影响第一版理解的过时文档。

验收条件：

- README 命令可以在干净环境运行；
- 主流程没有阻断性错误；
- 模型异常时可以明确解释并安全降级；
- 文档与当前实现一致；
- 后端测试、Ruff、前端类型检查和生产构建通过。

## Later：生产化能力

以下能力不属于第一版 Demo：

- PostgreSQL 和数据迁移；
- 可恢复任务队列与幂等执行；
- 认证、多用户与权限控制；
- 限流、调用预算、日志、监控和告警；
- 不可变 Atlas 版本与回滚；
- 正式部署、备份与灾难恢复；
- 多来源研究、来源评级和独立 Reviewer。

## 当前最小演示目标

```text
创建 LearningBrief
→ 确认 FrameworkPlan
→ 生成 ResearchPack 与 AtlasDocument
→ 在迷雾地图探索关系
→ 完成一次自测并定位复习概念
```
